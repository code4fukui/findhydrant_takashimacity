# findhydrant_takashimacity


滋賀県高島市にある消火栓や防火水槽などの消火用水源の位置を表示するウェブアプリケーションです。市が公開しているオープンデータを活用しています。

## デモ

https://code4fukui.github.io/findhydrant_takashimacity/

## 機能

- 消火栓や防火水槽、プールなどのさまざまな消火用水源をインタラクティブな地図上にプロットします。
- 水源の種類に応じて異なるアイコンで表示します。
- ユーザーの現在地（GPS）に最も近い水源を検索します。
- 各地点の詳細（種類、住所、容量など）を表示します。
- 地図インターフェースは、国土地理院（GSI）が提供する地図タイルを使用し、Leafletを利用して構築されています。

## データソース

このアプリケーションは、「高島市 消火栓情報」オープンデータセットを使用しています。このデータは [BODIK.jpプラットフォーム](https://data.bodik.jp/dataset/252123_fire_hydrant_format) で公開されています。

データは複数のCSVファイル（市内の各エリアごとに1ファイル）として提供されており、このリポジトリに含まれています。

## 使い方

ビルドやインストールは必要ありません。

1. このリポジトリをクローンします。
2. モダンなウェブブラウザで `index.html` ファイルを開きます。

*注: 特にGPS機能を使用する場合、最適な動作を得るためにローカルのウェブサーバー経由でファイルを開くことを推奨します。*
